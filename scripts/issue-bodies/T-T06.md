## Summary
Filter, search, edit, archive, view download stats. Storage quota indicator. (US-TCH-002)

## Scope
- Filter chips: grade / subject / term / material type.
- Search by title or tag.
- Edit metadata (title / description / tags).
- Archive / unarchive.
- viewCount per material from list DTO.
- Quota bar (warn at 80%, block at 100% -- backend-enforced).

## Acceptance Criteria
- [ ] Filters and search reflect server state, not just client filtering.
- [ ] Quota indicator visible.
- [ ] tsc clean.
