## Summary
Spreadsheet-style mark capture per assessment. (US-TCH-008)

## Scope
- `app/teacher/mark-sheets/page.tsx` lists assessments -> click in opens mark-capture page.
- Row per enrolled student: mark / percent (auto) / achievement level (auto, SA 7-level) / feedback / notes.
- Bulk save via `BulkRecordMarksAsync`.
- Locked indicator for published marks.

## Acceptance Criteria
- [ ] Mark range validation client + server.
- [ ] Achievement level auto-derives from percent.
- [ ] Cannot edit a published mark unless server returns unlocked.
- [ ] tsc clean.

## Business Rules
BR-GR-001..006 (mark range, percentage, 7-level). TF-001..005 (feedback length 20-2000).
