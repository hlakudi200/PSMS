## Summary
Upload-new-version flow with auto-incrementing version, change description, restore previous. (US-TCH-003)

## Scope
- Action on existing material: `Upload new version`.
- Required: change description.
- Auto-increment displayed version (1.0 -> 1.1).
- Version history drawer with download + restore buttons.

## Acceptance Criteria
- [ ] Old version reachable from history.
- [ ] Restore creates a new version equal to a chosen old one -- never overwrites history.
- [ ] tsc clean.

## Business Rules
LM-003 (retain up to 10 versions).
