## Summary
48-hour edit window for feedback on published marks + edit history. (US-TCH-010)

## Scope
- Edit-feedback flow on a published mark.
- Server enforces 48-h window. UI checks `publishedAt` and disables edit after 48 h.
- Edit history drawer with timestamps.
- Inappropriate-language scan happens server-side; UI shows rejection.

## Acceptance Criteria
- [ ] Within 48 h: edit allowed, history updated.
- [ ] After 48 h: edit blocked client-side and server-side.
- [ ] tsc clean.
