## Summary
List the classes the current teacher is assigned to, with quick links into roster/attendance/marks for each class.

## Scope
- `app/teacher/classes/page.tsx`.
- Provider call: `ITeacherClassAppService.GetByTeacher` scoped to current user.
- Card per class: class name, grade, subject, student count.
- Quick links: View Roster, Take Attendance, Mark Sheets.

## Acceptance Criteria
- [ ] Only the current teacher's assigned classes appear.
- [ ] Empty state when no classes assigned.
- [ ] Clicking a class opens its detail (separate ticket scope).
- [ ] tsc clean.

## Business Rules
Permissions Matrix: teacher scope = assigned classes/subjects only.
