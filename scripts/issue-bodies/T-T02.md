## Summary
Replace the stub TeacherDashboard with real metrics and a recent-activity feed pulled from existing providers.

## Scope
- Metrics cards: My Classes (TeacherClass scoped to current user), Total Students across my classes, Pending Mark Sheets (assessments with markCount < students), Today's Lessons (OnlineLessons today + Timetable slots today).
- Recent activity feed: upcoming lessons, recent announcements targeted to teachers.
- Error states + loading states.

## Acceptance Criteria
- [ ] No hardcoded zeros -- all values come from providers.
- [ ] Cards are keyboard-accessible (role=button, tabIndex, onKeyDown).
- [ ] Uses `variant="borderless"` not deprecated `bordered={false}`.
- [ ] Failed fetches surface via `<Alert>` inside the relevant card.
