## Summary
Recording upload modal on completed lessons. (US-TCH-006)

## Scope
- Available on lessons with status = Completed.
- File picker: MP4 / MOV / AVI / WebM (5 GB advisory cap, server-enforced).
- Required: link to lesson, filename includes Subject-Grade-Date-Topic.
- Submit via `addRecordingAsync`.

## Acceptance Criteria
- [ ] Cannot attach a recording to a not-yet-completed lesson.
- [ ] Server-side rejections (size, virus scan) surface via interceptor.
- [ ] tsc clean.

## Business Rules
OL-003, OL-004 (access server-side), OL-005 (retention server-side).
