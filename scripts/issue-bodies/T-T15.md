## Summary
Daily class attendance register. (US-TCH-011)

## Scope
- `app/teacher/attendance/page.tsx`.
- Select class + date (no future dates, default today).
- List of enrolled students with quick-mark Present/Absent/Late/Excused + per-row notes for absences.
- Bulk save via `BulkCaptureAsync`.
- Visual lock indicator when current day passes midnight.

## Acceptance Criteria
- [ ] Future-date selection disabled.
- [ ] After midnight: form locked unless admin override (server-side).
- [ ] Save success shows summary (e.g. `28 present, 2 absent`).
- [ ] tsc clean.

## Business Rules
AT-001..003 (statuses, midnight lock, parent same-day notification -- server-side).
