## Summary
Bulk mark import via Excel: download template, preview, validate, atomic commit. (US-TCH-009)

## Scope
- `Import marks` button on mark capture page.
- Step 1: download .xlsx template (headers: StudentIdNumber, SubjectCode, AssessmentType, Mark, MaxMark).
- Step 2: upload (XLSX/XLS/CSV <= 10 MB, <= 1000 rows).
- Step 3: preview first 10 rows + validation summary (total / valid / invalid) + downloadable error report.
- Step 4: confirm -> atomic commit through existing `BulkRecordMarksAsync`.

## Acceptance Criteria
- [ ] Any invalid row blocks import.
- [ ] Preview shows correct headers detected.
- [ ] Success message shows row count imported.
- [ ] tsc clean.

## Business Rules
EI-001..004 (file format, validation, preview, atomic transactions).
