## Summary
Materials list + upload modal with Zod-validated form. (US-TCH-001)

## Scope
- `app/teacher/materials/page.tsx` + `MaterialUploadModal`.
- File picker: PDF/DOC/PPT/MP4/MP3/images/ZIP. Size: docs ≤ 50 MB, video ≤ 500 MB.
- Form (Zod): title 5-200, description 10-1000, grade, subject, term, material type, core/supp, up to 5 tags.
- Submit via `LearningMaterialProvider.createAsync`.

## Acceptance Criteria
- [ ] Validation runs before submit.
- [ ] Server rejection (e.g. virus scan failure) is surfaced via the axios interceptor.
- [ ] Success toast only on actual success (catch path stays silent -- interceptor shows the error).
- [ ] tsc clean.
