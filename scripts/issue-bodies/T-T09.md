## Summary
UI scaffolding for starting / ending a live class. WebRTC embedding deferred. (US-TCH-005)

## Scope
- `Start` button on scheduled lessons -> calls `OnlineLessonProvider.startAsync`.
- After start: show meeting link with copy-to-clipboard + `Open meeting` button.
- `End` button -> `endAsync` with attendee count.
- `Cancel` button -> `cancelAsync`.

## Acceptance Criteria
- [ ] Start link active only 15 min before scheduled start (server-side check).
- [ ] End is irreversible; UI confirms.
- [ ] Live video embed is OUT OF SCOPE -- flagged on the PR description.
